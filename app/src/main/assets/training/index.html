    About Hok6

    Hok6 (學, hok6) — where you learn, study, and imitate.

    Device settings

    Menu names differ a little between makers; if one isn't where it's shown, search for it in Settings.

    • Chinese voices for 🔊 and the Sound → Chinese quiz: Settings → System → Languages & input → Text-to-speech output → engine Speech Services by Google → ⚙ → Install voice data → Chinese (Hong Kong) / 粵語 for Cantonese and Chinese (China) / 普通话 for Mandarin.
    • Internet once: the first time you tap ✍ Write by hand, the handwriting model downloads; after that it works offline, like everything else.
    • Backup (nothing to set): your writing, tracing, history and quiz are kept in your book folder as Hok6 backup.json, on the device, not in Google Drive. After reinstalling, choose the same book folder and tap Restore. Back up… under History saves a copy anywhere else.
    • Install unknown apps (for updates): Settings → Apps → Special app access → Install unknown apps → the browser or Files app → Allow from this source. If Play Protect warns, tap More details → Install anyway.
    • Stylus (optional): once Hok6 sees a stylus, only the stylus writes and fingers scroll, so your hand can rest on the screen.
