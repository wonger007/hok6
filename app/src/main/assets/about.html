Device tips

Menu names differ a little between makers; if one isn't where it's shown, search for it in Settings.

  • Voices for 🔊 and the Sound → word quiz: Settings → System → Languages & input → Text-to-speech output → engine Speech Services by Google → ⚙ → Install voice data → the voice for each language you're learning.
  • Internet once: Settings → Download all (⋮ → Settings on the main screen or in Practice & Quiz; also offered on first start) gets the handwriting models and opens the voice screen for you; after that Hok6 works offline. The dictionary is built in.
  • Backup (nothing to set): your writing, tracing, history and quiz are kept in your book folder as Hok6 backup.json, on the device, not in Google Drive. After reinstalling, choose the same book folder and tap Restore. Back up… under History saves a copy anywhere else.
  • Install unknown apps (only for Hok6 installed from GitHub, to update it): Settings → Apps → Special app access → Install unknown apps → the browser or Files app → Allow from this source. If Play Protect warns, tap More details → Install anyway.
  • Samsung tablets: turn off Auto Blocker to install or update Hok6 (Settings → Security and privacy → Auto Blocker). For voices, Samsung's own engine may have no Cantonese: install Speech Recognition and Synthesis from Google from the Play Store, then Settings → General management → Text-to-speech → Preferred engine → that one → ⚙ → Install voice data. A book on a microSD card: in the folder picker, tap ☰ and pick the SD card.
  • Stylus (optional): the ✍ Stylus / ☝ Finger toggle in the title bar says who writes. With ✍ Stylus only the stylus writes and fingers scroll, so your hand can rest on the screen. Lost the stylus? Tap it for ☝ Finger.
